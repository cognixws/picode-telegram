# 2026-10-15 — host-tls: trust the explicitly configured host certificate
Version 0.1.2 fixes Host API HTTPS requests when hostcert.pem contains a CA-issued mkcert leaf certificate: Node rejected that explicit trust anchor with UNABLE_TO_VERIFY_LEAF_SIGNATURE.
The deployed dev failure on port 8445 was reproduced with an unauthenticated request; no secret was read. Explicit partial-chain trust then reached the verified-TLS 401 Unauthorized baseline.
Host API requests alone enable allowPartialTrustChain when supplying their explicit ca; generic jsonRequest defaults to false and Telegram provider TLS behavior is unchanged.
Reference: https://nodejs.org/download/release/v25.9.0/docs/api/tls.html
Verification: npm test PASS, 47 tests; git diff --check PASS. The generated CA-issued TLS fixture proves rejection without the flag, success with the explicit leaf, and rejection of a wrong hostname or unrelated certificate; only one HTTPS request reaches the handler.
